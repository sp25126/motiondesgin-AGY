# The Critique Loop
Before rendering the final MP4, you must grade your code on a scale of 1-10 in these categories:
1. **Depth:** Are there foreground, midground, and background elements moving at different parallax speeds? (Target: 8+)
2. **Snappiness:** Are the easing curves dynamic (fast start, slow settle) rather than floaty/linear? (Target: 8+)
3. **Cohesion:** Do UI elements morph seamlessly instead of fading in and out? (Target: 8+)

If any score is below 8, you MUST rewrite the Remotion components to fix it before proceeding to render.
